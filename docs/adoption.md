# Ambiflex adoption log (node n14)

One row per weekly snapshot, taken by a scheduled task in the Ambiflex session every Monday. **Primary metric (from 20 October 2026): unique cloners**, since a plugin install is a clone and most installers never open the GitHub page (launch day: 39 unique cloners for 7 visitors). Targets at 90 days (18 January 2027): **1,000 unique cloners (cumulative)** · 500 stars (secondary) · 20 issues opened by others · 10 external PRs merged · 1 mention by someone at Anthropic. At 45 days with nothing at half, change the content angle, not the features.

Live page: the "Ambiflex adoption" dashboard at https://claude.ai/artifact/9p1cpn4pbL1vJMbrnvv4pa reads the same sources on every open (stars, forks, issues and pull requests by others, the daily traffic file) with the viewer's own GitHub connection.

Sources: GitHub API for `ImadeBenToumAI/ambiflex` (stars, forks, issues and PRs by others). Clones and views come from `docs/traffic.json` in that repository, written every day by its *Traffic snapshot* workflow (GitHub itself keeps them 14 days only); the workflow needs the repository secret `TRAFFIC_TOKEN`, a fine-grained token limited to the repository with *Administration: read-only*. Mentions are searched by hand (X, Hacker News, Reddit).
